# 程掌柜 · Hotel AI

> **Chengzhanggui — Hotel Investment Due Diligence Agent**  
> GOAI 无界应用｜AI+金融｜酒店经营体检与投资风险辅助研判

这是《程掌柜》面向 GOAI 无界应用创新大赛整理的公开演示仓库。仓库提供一个无需账号、无需 API Key、无需后端即可运行的可交互 Demo，使用**明确标注的模拟酒店数据**展示完整任务链。

## Demo 主链

1. 创建酒店尽调项目
2. 加载并核验模拟材料
3. 运行经营诊断
4. 查看决策门、风险红线与证据
5. 对比乐观 / 基准 / 压力三情景
6. 生成结论与 30 / 60 / 90 天行动计划

公开 Demo 聚焦可复现体验。正式产品工程中的账户、数据库、私有业务数据和内部基础设施未包含在本仓库。

## 直接运行

```bash
python -m http.server 8080
```

浏览器打开：

```text
http://localhost:8080/?demo=goai
```

也可以直接双击 `index.html` 使用大部分功能。

## 演示说明

- Demo 数据：模拟数据，不代表任何真实酒店或真实投资建议。
- 计算方式：浏览器内确定性计算 + 风险规则，用于展示产品工作流。
- 金融边界：输出仅用于经营与投资风险辅助研判，不替代投资人、金融机构、律师、会计师或其他专业机构的最终判断。
- 证据原则：关键结论可回看来源字段、计算条件和风险规则。
