# 程掌柜 · Hotel AI

> **Chengzhanggui — Hotel Investment Due Diligence Agent**  
> GOAI 无界应用｜AI+金融｜酒店经营体检与投资风险辅助研判

这是《程掌柜》面向 GOAI 无界应用创新大赛整理的公开演示仓库。

公开 Demo 直接沿用程掌柜真实产品 `HATWIN.html` 的页面结构与 V13 视觉基线：

- 左栏：程掌柜品牌、发起新咨询、项目档案、当前项目对话
- 中栏：对话工作台、聊天历史、真实风格输入 Dock
- 右栏：投资分析 / 经营分析工作台
- 工作阶段：资料 → 诊断 → 方案 → 结论
- 手机版：对话 / 投资分析 / 经营分析 / 项目四标签

为了满足公开开源与评委直接体验，赛事仓库移除了账号、数据库、私有业务数据、密钥和内部基础设施。演示数据层使用明确标注的模拟酒店数据，确定性指标、风险规则、Evidence Trace、三情景和行动计划均可直接运行。

## 在线 Demo

https://awkn-lab.github.io/hotel-ai/

## Demo 主链

1. 在真实风格的程掌柜工作台进入演示项目
2. 查看酒店经营、租赁、渠道、品牌与改造资料
3. 完成高影响字段确认
4. 运行经营诊断与风险研判
5. 查看决策门、风险红线、Agent 执行轨迹和 Evidence Trace
6. 对比乐观 / 基准 / 压力三情景
7. 形成条件推进结论与 30 / 60 / 90 天行动计划
8. 导出 Demo 报告

也可以直接在中间对话工作台输入：

- `把这个项目的关键风险给我`
- `给我看乐观基准压力三情景`
- `最后给我30 60 90天行动计划`
- `看经营诊断`

程掌柜会驱动右侧真实风格工作台切换到相应阶段。

## 本地运行

```bash
git clone https://github.com/AWKN-Lab/hotel-ai.git
cd hotel-ai
python -m http.server 8080
```

打开：

```text
http://localhost:8080/
```

无需账号、API Key 或数据库。

## 演示数据与边界

- 数据：公开 Demo 全部使用模拟数据，不代表任何真实酒店。
- 计算：浏览器内确定性计算 + 风险规则，用于展示产品工作流。
- 证据：关键风险可展开 Evidence Trace，查看字段、来源和规则。
- 金融边界：输出用于经营与投资风险辅助研判，最终判断由投资人及相关专业机构完成。
